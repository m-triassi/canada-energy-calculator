# canada-energy-calculator

A client-side web app that estimates your monthly household electricity bill in Canada. Add your appliances (or a whole-house baseline), pick a provincial rate preset or enter your own rates, and see your estimated monthly cost. The app handles tiered pricing and fixed daily fees, and shows a cost breakdown for each appliance.

## Features

-   **Provincial rate presets** for Quebec (Hydro-Québec Rate D), Ontario, British Columbia, Alberta, and Nova Scotia, plus a **Custom** mode.
-   **Editable rate settings:** Tier 1 rate, optional Tier 2 rate, a daily kWh threshold, and a fixed daily fee. Changing any value switches the preset to Custom.
-   **Tiered billing:** usage up to the monthly threshold (daily threshold × 30 days) is billed at the Tier 1 rate. Usage above it is billed at the Tier 2 rate.
-   **Appliance tracking:** enter a name, wattage, hours per day, and days per month for each appliance. If you leave hours or days blank, the app assumes the appliance runs all the time (24 h/day, 30 days/month).
-   **Monthly bill dashboard** with total kWh used, a blended rate per kWh, fixed fees, which tiers apply, and a bar showing how usage splits between Tier 1 and Tier 2.
-   **Cost for each appliance,** calculated by spreading the tiered energy cost evenly across all kWh using the blended rate.
-   **Saved in your browser:** your settings and appliance list are stored in `localStorage` and are still there when you come back.
-   **Responsive layout** built with Tailwind CSS and [Lucide](https://lucide.dev/) icons.

> **Disclaimer:** The preset rates are approximations and may be out of date. Check them against your utility's current rate schedule. Estimates assume a 30-day billing month and do not include taxes, delivery or regulatory charges, or time-of-use pricing.

## Quick Start

To get a local copy up and running, follow these simple steps.

1.  **Clone the repository:**
    ```sh
    git clone git@github.com:m-triassi/canada-energy-calculator.git
    cd canada-energy-calculator
    ```

2.  **Install dependencies:**
    ```sh
    npm install
    ```
    or if you use Yarn:
    ```sh
    yarn install
    ```

3.  **Run the development server:**
    ```sh
    npm run dev
    ```
    This will start the Vite development server. Open your browser and navigate to `http://localhost:5173` (or the port shown in your terminal) to see the application.

## Available Scripts

In the project directory, you can run the following commands:

-   `npm run dev`: Runs the app in development mode.
-   `npm run build`: Builds the app for production to the `dist` folder. It correctly bundles React in production mode and optimizes the build for the best performance.
-   `npm run lint`: Lints the project files for code quality and style issues using ESLint.
-   `npm run preview`: Serves the production build from the `dist` folder locally to preview it before deployment.

## Deployment

Every push to `main` runs the GitHub Actions workflow in `.github/workflows/deploy.yml`. It builds the app and deploys `dist/` to Cloudflare Pages. Pushes that only change `README.md`, `LICENSE.md`, or `.gitignore` do not trigger a deploy. You can also run the workflow by hand. The repository needs the `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` secrets.
